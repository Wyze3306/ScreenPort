Corrige les connexions qui finissent en **« Délai dépassé »** alors que le serveur répond bien.

## Nouveau

- **Désactiver le marquage QoS (IPQoS)** : nouvelle option dans les paramètres de chaque serveur, rubrique « Réseau ». Elle est **activée par défaut**, y compris pour les serveurs déjà enregistrés.
  ssh marque ses paquets pour la qualité de service ; certains réseaux (box, partage de connexion 4G/5G) les jettent, et la connexion expire avant même la demande de mot de passe. Avec l'option, ScreenPort passe `-o IPQoS=none` à ssh.
  Désactivée, l'option rend la main à `~/.ssh/config`.
- La commande copiée depuis un serveur inclut `-o IPQoS=none` quand l'option est active.
- Le message « Délai dépassé » indique désormais cette option.

## Installation

```bash
sudo apt install ./screenport_1.1.0_all.deb
```

La mise à jour conserve vos serveurs et mots de passe enregistrés.
