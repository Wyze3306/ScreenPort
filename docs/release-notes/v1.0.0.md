Première version de **ScreenPort**, client SSH graphique pour Linux : ouvrez plusieurs terminaux en même temps, chacun sur une session **GNU screen** au nom de votre choix. Si le screen n'existe pas, il est créé sur le serveur ; sinon ScreenPort s'y rattache directement.

![Vue mosaïque](https://raw.githubusercontent.com/Wyze3306/ScreenPort/v1.0.0/docs/screenshots/mosaique-clair.png)

## Installation

Ubuntu 24.04+, Debian 13+, Linux Mint 22+ et dérivées :

```bash
sudo apt install ./screenport_1.0.0_all.deb
```

Puis lancez **ScreenPort** depuis le menu des applications. Sur le serveur, seul `screen` est nécessaire.

## Fonctionnalités

- Serveurs enregistrés (adresse, utilisateur, port ; mot de passe, clé privée ou agent SSH), avec couleur et screens favoris
- Connexion rapide en collant `utilisateur@hôte:port`, test de connexion depuis le formulaire
- Fenêtre « Ouvrir des screens » : liste des screens existants, création de plusieurs screens d'un coup
- Onglets colorés par serveur, vue mosaïque, plusieurs fenêtres
- Renommer, terminer ou rouvrir un screen ; fermer un onglet laisse le screen tourner
- Une seule authentification par serveur (connexion SSH partagée)
- Reconnexion automatique après une coupure et réouverture des onglets au démarrage
- Mots de passe dans le trousseau du système, transmis à ssh uniquement pour l'invite attendue
- Import des hôtes de `~/.ssh/config`, thèmes clair/sombre, 10 palettes de terminal
